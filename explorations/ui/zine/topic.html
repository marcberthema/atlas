OpenGitOps principles

analysed v1.0.0checked 2026-10-26activeunconfirmed

Four principles that define GitOps: declarative, versioned and immutable, pulled automatically, continuously reconciled.

  • GitOps is a way to run a system where the desired state lives in version control, and software agents keep the real system equal to it.
  • OpenGitOps (v1.0.0) states it as four principles. Everything else on this page, Argo CD, Flux, Helm and Kustomize, is a tool to apply them.

Gotcha!In a push pipeline, CI applies changes to the cluster. In a pull model, an agent fetches the desired state and applies it itself. Argo CD's docs say that with automated sync, CI only has to push a commit and not call the Argo CD API.

Argo CD

analysed v3.5.6checked 2026-10-26activeApache-2.0

Declarative GitOps continuous delivery for Kubernetes, with a web UI, a CLI and multi-cluster support. The main subject of this topic.

  • Argo CD is a Kubernetes controller for GitOps. You describe the applications you want in Git, and Argo CD keeps comparing that desired state with the live state in the cluster.
  • When the two differ the application shows as OutOfSync, and Argo CD can sync it back, manually or automatically.
  • It renders Kustomize, Helm, Jsonnet, plain YAML or JSON, and custom config management plugins, then applies the result.

Gotcha!Argo CD is one application with a UI and an API server, and drift correction is opt-in (selfHeal). Flux is a set of controllers with custom resources, and its Kustomization reverts drift by default. See the Compare tab.

Flux

analysed v2.10.0checked 2026-10-26activeApache-2.0

A set of Kubernetes controllers (the GitOps Toolkit) that keep a cluster in line with Git, OCI, Helm or bucket sources. The closest competitor to Argo CD.

  • Flux is a set of Kubernetes controllers (the GitOps Toolkit) that keep a cluster in line with Git, OCI, Helm or bucket sources. It is the closest competitor to Argo CD.
  • Each controller owns a few custom resources. A source controller fetches, and the kustomize and helm controllers apply what was fetched.

Gotcha!Argo CD is one application with a UI and an API server, and drift correction is opt-in (selfHeal). Flux is a set of controllers with custom resources, and its Kustomization reverts drift by default. See the Compare tab.
