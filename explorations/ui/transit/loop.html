DevOps loop

The eight stages, and where each topic fits. A topic can belong to several stages.

Dev

1Plan

Decide what to build: requirements, backlog, design.

  • Architecture and design patterns
  • Enterprise topologies

2Code

Write and review source code and infrastructure code.

  • Terraform
  • Architecture and design patterns

3Build

Compile, package and store the artifacts.

  • GitHub Actions

4Test

Automated tests, scans and quality gates.

  • GitHub Actions

Ops

5Release

Version, approve and promote artifacts.

  • GitHub Actions
  • GitOps

6Deploy

Roll changes out to environments.

  • GitHub Actions
  • Azure with Terraform
  • Terraform
  • GitOps
  • Certificates
  • Identity providers

7Operate

Run, scale, configure and secure what is deployed.

  • Azure with Terraform
  • GitOps
  • Certificates
  • Identity providers
  • Enterprise topologies

8Monitor

Metrics, logs and alerts, and the feedback into planning.

  • Azure with Terraform

Which stages a topic belongs to is a judgement recorded in the topic's spec, not something a source states.
